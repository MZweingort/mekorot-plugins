# מילוי מראי מקומות בסיכום שיעור

הקלט: קובץ docx של סיכום שיעור. רוב הערות השוליים כבר מלאות; חלקן ריקות או מכילות `???`. הפלט: אותו קובץ, עם ההערות הללו מלאות, **כל שינוי במעקב שינויים** ("Claude"), וכל מקור לא ודאי מסומן ב-comment. מה שלא נמצא – נשאר כמות שהוא.

## כללי ברזל
1. לגעת רק בהערות ריקות / `???`. לא לשנות טקסט בגוף ולא הערות מלאות.
2. סדר עדיפות לחיפוש: (א) `references/arachim.md` – קובץ הערכים; (ב) פסוקים – מהידע, לוודא פרק/פסוק; (ג) ארכיון השיעורים (שלב 3 – דרך הקונקטור, או ישירות עם `scripts/archive.py`); (ד) ידע כללי רק לציטוטי חז"ל/זהר מוכרים היטב.
3. לא לנחש. מקור לא ודאי → למלא **וגם** comment שמתחיל ב"מקור לא ודאי –". לא נמצא → להשאיר ריק / להשאיר `???`, ולדווח.
4. סגנון ציטוט כמו בקובץ הערכים (ראו `references/conventions.md`): `זהר ח"ב קכא, א.` · `לקו"ת נצבים מט, ד.` · `ע"פ ברכות יג, ב.` · `ראה ... ובכ"מ.`
5. לעולם לא לקרוא את `arachim.md` בשלמותו (1.4MB). רק grep.

## שלב 1 – רשימת ההערות למילוי
```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/milui-mekorot/scripts/footnotes_tool.py" list shiur.docx
```
מדפיס לכל הערה ריקה/`???` את מספרה, תוכנה, ואת הקטע בגוף המסמך שאליו היא מפנה (`[*]` = מקום ההערה). מכאן מסיקים לכל הערה מה הביטוי/הציטוט שצריך מקור.

(אם המשתמש העלה גם את קובץ הערכים בגרסה חדשה יותר: `pandoc -t gfm --wrap=none arachim.docx | sed -E 's#<span dir="rtl">##g; s#</span>##g; s#\\([*"\x27\[\]_])#\1#g' > arachim.md` ולהשתמש בו במקום זה שב-references.)

## שלב 2 – חיפוש בקובץ הערכים
לחפש כמה ביטויים בבת אחת, בכמה ניסוחים (עם/בלי גרשיים, מלה מרכזית בלבד, קיצור):
```bash
A="${CLAUDE_PLUGIN_ROOT}/skills/milui-mekorot/references/arachim.md"
for t in "מחכמה נפקת" "וראית את אחורי" "מתוך גרונו" "אלופו של עולם"; do echo "=== $t"; grep -n -F "$t" "$A" | head -8; done
```
מבנה הקובץ: כל ערך שורה אחת (`ביטוי – מקור.`), תת-ערכים בשורות שמתחילות ב-`>`, כותרות `## א` לפי אות, וכותרות `### ערך` לערכים מרובי-סעיפים. הערות שוליים של הקובץ עצמו מסומנות `[^123]` ונמצאות בסופו – `grep -n "^\[\^123\]"`. כוכבית `*` בסוף ערך = מרשימת הרב עצמו (אמין במיוחד). כדי לראות הקשר: `sed -n "N,+4p" "$A"`.

אם הביטוי לא נמצא – לנסות מלה בודדת מהביטוי, מושג מקביל (למשל "ראיה ושמיעה" במקום "חכמה ראיה"), או את הערך הראשי של המושג (`grep -n "^### בינה"`).

## שלב 3 – ארכיון השיעורים
שרת אחד, שתי דרכים לגשת אליו (https://galeinai-mcp.vercel.app/api/mcp):
1. אם הקונקטור `galeinai-archive` מחובר בסשן (כלים `search_archive`, `get_document`, `ask_archive`, `browse_topics`) – להשתמש בו.
2. אם הוא לא מחובר או נכשל – **לא לדלג**: לקרוא לאותו שרת ישירות עם הסקריפט (ספריות תקן בלבד):
```bash
AR="${CLAUDE_PLUGIN_ROOT}/skills/milui-mekorot/scripts/archive.py"
python3 "$AR" ping                                         # בדיקת חיבור
python3 "$AR" search '"ביטוי מדויק"' --scope footnotes      # מ"מ שכבר צוטטו בהערות של שיעורים אחרים
python3 "$AR" search '"ביטוי" מלה' --tree lessons --full    # טקסט מלא של הקטעים
python3 "$AR" search 'דבר ירושלם' --scope titles --year 5777   # למצוא שיעור לפי כותרת/שנה
python3 "$AR" doc <doc_id> --section "כותרת"               # לקרוא מסמך/סעיף
```
רק אם גם `ping` נכשל (אין רשת בסשן) – לדלג, לא להתעכב.

איך לחפש: בעברית, 2-3 מלים בלשון הארכיון (לא פרפרזה); המלים מחוברות ב-AND, `"ביטוי"` לצירוף מדויק, `OR` לחלופות. אם בראש התוצאה כתוב `NOTE: the full query matched nothing together` – התוצאות לא עונות על כל השאילתה; לא להסתמך עליהן. `--scope footnotes` הוא הכלי העיקרי: הערה של שיעור אחר על אותו ציטוט מביאה בדרך כלל את המקור המדויק. `--scope titles` / `--year` (שנה עברית, 5777=תשע"ז) – להשלמת תאריך של "ראה שיעור ... ???".

ניסוח: הפניה לשיעור – "ראה שיעור אור ל-ה' תמוז תשע"ו" (תאריך מכותרת המסמך). מקור שנלקח מהערה בארכיון ולא אומת בקובץ הערכים – למלא וגם comment: "מקור לא ודאי – מהארכיון (<קישור>)".

## שלב 4 – קובץ המילויים
לכתוב `fills.json` (מבנה מלא ב-`examples/fills.example.json`):
- `fill` – הערה ריקה: `"92": "זהר ח\"ב קכא, א."`
- `replace` – מחרוזת בתוך הערה קיימת (למשל `(???)` → `(בראשית ב, ד)`). המחרוזת חייבת להימצא ב-run אחד; אם הכלי מדווח 0 או 2+ – להרחיב/לצמצם את המחרוזת או להשתמש ב-`replace_runs`.
- `replace_runs` – מחליף רצף runs מ-`first` עד `last` (ל-`???` שמפוצל על כמה runs).
- `comments` – לכל מקור לא ודאי: `{"id": 93, "text": "מקור לא ודאי – ..."}`. ה-comment מעוגן על סימן ההערה בגוף המסמך (לא בתוך footnotes.xml – זה שובר את LibreOffice).

## שלב 5 – החלה, אימות, מסירה
```bash
T="${CLAUDE_PLUGIN_ROOT}/skills/milui-mekorot/scripts/footnotes_tool.py"
python "$T" apply shiur.docx fills.json "shiur - עם מקורות.docx" --author Claude
python "$T" verify "shiur - עם מקורות.docx" --original shiur.docx --fills fills.json
```
`verify` הוא הבדיקה המחייבת והיא עובדת בכל מקום (python בלבד): שלמות ה-zip וה-XML, שכל השינויים במעקב שינויים, שמספר ההערות לא השתנה, ושכל המילויים וה-comments נכנסו. כל שורת FAIL – לתקן ולהריץ שוב, לא למסור.

בדיקות נוספות **אם הכלים קיימים במחשב** (`command -v soffice`, וסקריפט ה-docx skill) – רצוי אך לא חובה, ואם הן חסרות פשוט מדלגים בלי להתקין כלום:
```bash
command -v soffice >/dev/null && soffice --headless --convert-to pdf --outdir . "shiur - עם מקורות.docx"
```
למסור את הקובץ, ובסיכום למשתמש: (1) מה מולא ובאיזה מקור, (2) מה סומן כלא-ודאי ולמה, (3) מה נשאר ריק. בלי להעתיק את כל ההערות – רשימה תמציתית.

## סביבה
עובד גם ב-Cowork וגם ב-Claude Code. הסקריפט משתמש ב-python3 בלבד (ספריות תקן, בלי התקנות). ב-Claude Code הקבצים הם קבצים מקומיים של המשתמש: לעבוד עליהם במקום, לכתוב את הפלט לצד קובץ המקור, ולא להעביר לשום מקום. `pandoc` נדרש רק אם ממירים קובץ ערכים חדש; `soffice` רק לבדיקה האופציונלית.

## מספור
מספר ההערה ב-`list` = `w:id` ב-footnotes.xml = מספר ה-`[^N]` בפלט `pandoc -t markdown` של המסמך. ids −1 ו-0 הם מפרידים, לא הערות.
