# מוסכמות ציטוט (כפי שנהוגות בקובץ הערכים)

- פסוק: `שמות לג, כג.` · `משלי ח, כב.` · `ישעיה יא, ג.` · `שמואל-א טו, ד.` · `מלכים-א א, ה.`
- גמרא: `ברכות יז, ב.` · `מנחות צט, א-ב.` ; משנה: `אבות פ"ה מ"א.` ; ירושלמי: `ירושלמי ר"ה פ"ג ה"ח.`
- מדרש: `בראשית רבה א, ד.` · `תנחומא נשא טז.` · `ילקו"ש ישעיהו תקג.` · `תנדב"א פי"ד.`
- זהר: `זהר ח"ב קכא, א.` · `תקו"ז תקון נז (צא, ב).` · `זהר ח"ב קטז, ב (ברע"מ).`
- כתבי האריז"ל: `ע"ח ש"ד פ"א.` · `ע"ח שער הכללים פי"ג.` · `פע"ח שער הק"ש פט"ו.` · `שעה"כ דרושי חנוכה דרוש א.`
- חסידות: `תניא פל"ו.` · `לקו"ת נצבים מט, ד.` · `תו"א מקץ לד, ג.` · `אוה"ת עקב עמ' תעט.` · `מאמרי אדה"ז תקס"ג ח"ב עמ' תרעז.` · `לקו"ש חכ"ח מטות א.` · `סה"ש תש"ג עמ' 188.` · `לוח "היום יום" כח חשון.`
- בעש"ט: `כש"ט (קה"ת) אות ה.` · `הוספות לכש"ט (קה"ת, הוצאה שלישית) אות קסט.`
- ספרי הרב: `סוד ה' ליראיו ש"ח.` · `מלכות ישראל ח"א מאמר "..." (עמ' שיט).` · `אור ישראל ח"א עמ' מ.`
- שיעורים של הרב: `ראה שיעור כ"ט שבט תשע"א.` · `ראה באריכות התוועדות ח"י אלול תשפ"ג.`
- מילות קישור: `ע"פ ...` (המקור אינו הציטוט המדויק) · `ראה ...` (הפניה להרחבה) · `ובכ"מ.` (וברבוי מקומות) · `וש"נ.` (ושם נסמן) · `שם` (אותו ספר כבהפניה הקודמת).
- כמה מקורות: מופרדים ב-`;`. סוגריים להערת הבהרה: `לקו"ת ראה כז, א (ע"פ ע"ח שמ"ב פ"א).`
- ההערה מסתיימת בנקודה. בלי "עמוד"/"דף" – רק המספר.

# קיצורים נפוצים בקובץ הערכים
לקו"ת = לקוטי תורה (אדה"ז) · תו"א = תורה אור · אוה"ת = אור התורה (צ"צ) · או"ת = אור תורה (המגיד) · מבו"ש = מבוא שערים · ע"ח = עץ חיים · פע"ח = פרי עץ חיים · שעה"כ = שער הכוונות · שה"ש = שיר השירים · פלה"ר = פלח הרמון · לקו"ב = לקוטי ביאורים (ר' הלל) · סה"מ / סה"ש = ספר המאמרים / ספר השיחות · לקו"ד = לקוטי דיבורים · אג"ק = אגרות קדש · כש"ט = כתר שם טוב · מאו"א = מאורי אור · הרנ"ש = ר' נתן שפירא · ש"ג פ"ב = שער ג פרק ב · פנ"ו = פרק נו · מהדו"ת = מהדורה תנינא · הערות `[^N]` בקובץ = הערות שוליים שלו (בסוף הקובץ). `*` בסוף ערך = מרשימת הרב.
